# Amway Refreshments

**Technologies:** Swift 2.x, Realm Database, IoT Integration

An iOS application developed to help Uber drivers generate leads for Amway, built in collaboration with Andy Anderson (previously worked together on HarperCollins projects and the Seth Godin App).

## Project Overview

What began as a native prototype evolved into a fully functional application within two weekends of development. The solution was field-tested in the United Kingdom.

## Technical Highlights

### Rock-Solid Stability

The app achieved hundreds of hours of use without a single crash—a testament to Swift's design and careful implementation.

### Realm Database

This project marked my first substantial experience with Realm as an alternative to Core Data. Key advantages discovered:

- **Simpler development experience** than Core Data
- **Superior performance metrics**
- **Platform-agnostic file format** for cross-platform compatibility

While I generally prefer standard iOS frameworks, Realm's genuine technical benefits justified its inclusion in this project.

## Collaboration

This project was a collaboration with Andy Anderson, a designer I had worked with previously on several HarperCollins publishing apps including The Beginner's Bible.
